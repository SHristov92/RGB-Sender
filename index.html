Before you start

  1. Turn brightness to maximum and switch off auto‑brightness, Night Shift / blue‑light filter, True Tone and battery saver.
  2. Hold the sensor flat against the centre of the screen inside its light shield.
  3. Tap Start sending. The screen flashes until you tap it again. The message repeats, so the board can start listening at any time.
